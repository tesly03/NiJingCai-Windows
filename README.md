# 尼精彩 Windows 客户端（NiJingCai-Windows）

基于安卓 APK（尼精彩 1.2.3）逆向协议重新开发的 Windows 桌面客户端，用于通过蓝牙（BLE）控制「泥神 / NiShen」系列散热设备（水冷 / 液冷 / 风冷 / 散热器）。

## 功能

- **设备扫描与连接**：全量扫描周围 BLE 设备，自选连接
- **开机 / 关机**：与手机端一致的 `F5 55 02` 命令
- **灯效设置**：8 种灯效模式（彩虹旋转 / 彩虹渐变 / 星空 / 彩虹呼吸 / 呼吸 / 跑马灯 / 常亮 / 抖动），自定义颜色、饱和度、亮度、速度
- **性能设置**：温控 / 静音 / 超频 / 自定义四模式互斥切换，风扇转速（1~6 档）与功率（1~100W）调节
- **实时状态**：实时功率、温度、工作模式、风扇档位，2 秒轮询刷新
- **更多设置**：定时开关机、电压档位等

## 环境要求

- Windows 10 / 11（64 位）
- 支持蓝牙 4.0+ 的蓝牙适配器
- .NET 不需要，Electron 自带运行时

## 安装

从 [Releases](../../releases) 下载最新的 `尼精彩 Setup x.x.x.exe`，双击安装即可。

## 从源码运行

```bash
npm install
npm start
```

> 提示：国内网络环境下建议设置镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`

## 打包

```bash
npm run dist   # 生成 NSIS 安装包（dist/ 目录）
```

## 技术栈

- Electron 33 + Web Bluetooth（Chromium 原生 BLE GATT）
- 纯前端实现（HTML/CSS/JS），无第三方运行时依赖

## 蓝牙协议（逆向自 尼精彩_1.2.3.apk）

- Service UUID：`0000ff20`（写 `ff21`，通知 `ff22`）
- 命令帧：12 字节，`F5 55 <命令码> <数据…补零>`，无校验
- 常用命令码：`0x02` 开关、`0x03` 转速、`0x05` 功率、`0x09` 灯效、`0x0a` 温控、`0x0b` 超频、`0x0c` 静音、`0x10` 定时、查询类 `0x81~0x98`
